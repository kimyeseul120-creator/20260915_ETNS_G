문제 1 · Vercel 프로젝트 이름

Vercel 프로젝트 이름은 소문자만 허용됩니다. 20260915_ETNS_V → 20260915_etns_v 로 수정해 생성했습니다.

문제 2 · 정적 파일(CSS) 404

최초 vercel.json이 /static 요청을 잘못된 경로로 보내 스타일이 깨졌습니다. 해당 라우트를 지우고 모든 요청을 Flask 앱이 직접 처리하도록 수정 → 정상 표시 확인.

문제 3 · 데이터가 저장되지 않음

Vercel은 서버리스 구조라 파일(SQLite)이 재배포·재시작 시 초기화됩니다. DATABASE_URL 환경변수로 Supabase(Postgres)에 연결하도록 코드를 수정해 영구 저장으로 전환했습니다.

Maintenance

앞으로 코드를 수정하려면

  1. 1로컬 ETNS_TODO_APP 폴더에서 코드 수정
  2. 2git add -A && git commit -m "수정 내용" && git push 실행
  3. 3Vercel이 GitHub 변경을 감지해 1~2분 내 자동으로 새 버전 배포
  4. 4이미 저장된 할 일 데이터는 Supabase에 그대로 남아있으므로 재배포와 무관하게 유지됨
